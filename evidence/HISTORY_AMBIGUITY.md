# 同历史、不同未来：v26 的有界事后分析

日期：2026-09-08。新增计算只对已有30个候选损失作标准库算术，没有训练、选种子或更改原门槛。此分析是 post-hoc（事后分析），不是原主要指标，不宣称新颖性。

## 结果与研究含义

v26 的 decrease 与 return 在同一种子下共享完整训练历史、验证分割、验证损失和所选模型；已有原始数组审计核实5对训练历史相同。未来分别保持斜率0和恢复斜率1。五对实例的未来最优候选均不同。

在冻结的六候选库内，要求两种未来采用同一个选模分布时，最优的随机选模策略仍有以下最坏情形期望遗憾：

|种子|固定选择的最小最坏遗憾|随机选择的最小最坏期望遗憾|
|---|---:|---:|
|201|0.240716|0.161599|
|202|0.334850|0.211944|
|203|0.123676|0.099941|
|204|0.262333|0.166312|
|205|0.173216|0.130361|

以上数值均以该种子的训练目标方差归一化，无单位。不是Agent实测成绩，不是总体风险下界，不是置信区间；五个有限样本不能给出普遍发生率。

## 可核对的定义

对未来情形 w 和候选 m，令 L(w,m) 为保存的未来均方误差，V 为这一对共享的训练目标方差。有限库遗憾为 r(w,m)=[L(w,m)-min_j L(w,j)]/V；j遍历六个冻结候选。它比较同一有限未来样本上的库内最佳候选，而不是不可知总体最优解。

固定选择的值为 min_m max_w r(w,m)。随机选择的值为 min_p max_w sum_m p(m)r(w,m)，其中 p(m) 是选择候选m的概率，非负且总和为1。这里先随机选出一个完整模型；不能把它解释为对预测值取加权平均的集成模型。

两种情形的损失向量构成二维平面上的六个点；随机选择产生它们的凸组合。最小化两坐标最大值时，最优点在顶点或边界线段上。程序因此检查所有单候选，以及所有两候选混合在两坐标相等处的合法交点，不需要优化器或训练。这是对冻结候选损失矩阵的精确有限枚举，只有浮点舍入误差。

## 何时才能将其解释为信息限制

若 Agent 在两种情形看到的全部信息相同——不仅训练数据相同，部署说明、工具输出、外生协变量及其他线索也相同——则它不能让选模分布依赖尚未被揭示的未来情形。上述最坏情形代价因此无法仅靠换验证方法消除。

v26 是脚本机制诊断，没有实际运行这套 Agent 信息接口。因此本分析只是条件性论证，不声称已经建立了真实盲测。若任务告诉 Agent 系数将恢复、给出可预测该变化的线索，或允许使用库外候选/预测集成，上述有限库边界不再直接适用。

## 对后续任务的具体约束

时间顺序本身不足以给“时间验证必须选对”提供正确答案。下一份任务契约必须说明预测时可获得哪些关于未来变化的信息，并区分可解释的部署差异与不可预告的机制变化。return 条件可作边界案例，不能直接计为 Agent 能力错误。当前不据此开放正式 Agent/Skill 评价，也不追加样本寻找通过结果。
