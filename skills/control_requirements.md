# 等 token 控制的准入要求

Token-matched control 指长度按被测模型真实分词器匹配、但不含有效验证方法内容的对照文本。当前没有匹配结果，不能把字符数相等或字节数相等当成 token 匹配。

冻结前审查主题中性、语气和结构相近、不给 split 提示、不改变任务目标；同时记录 tokenizer 名称/版本、双方 tokens、注入位置、完整文本哈希。不同模型可能需要不同控制文件。不得用随机乱码充当等价任务负担的证据。

尚无匹配完成的控制组。AI 内容审查与实际 tokenizer 计数可以独立完成，但不得声称它们是外部人类复核。本开发版不提供 Skill 效果结论。
